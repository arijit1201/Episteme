# Starters

Each folder here is a complete, runnable agent project created from `templates/starter/` with the `/new-starter` skill.

Every starter works two ways:

- **BYOK:** copy `.env.example` to `.env`, add your provider key, set the provider in `config.yaml`, run it.
- **Harness:** open the folder in your coding agent (Claude Code, Codex, Cursor, others) and ask it to follow `SPEC.md` and `AGENTS.md`.

Planned order: `tool-agent`, `rag-agent`, `research-agent`. Then, one at a time: `coding-agent`, `browser-agent`, `multi-agent`, `voice-agent`.
